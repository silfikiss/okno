# Окно

Вид из окна на Москву: МГУ, Москва-Сити, Большой Московский цирк, Останкинская башня под карнизом.
Картинка меняется от времени года и месяца, времени суток (по настоящему солнцу над Москвой),
погоды (вручную или по прогнозу), света и ветра.

Сайт: https://adorable-treacle.netlify.app

## Что где лежит

Весь сайт — один файл `index.html`. Внутри три части:

1. **Оформление (`<style>`)** — цвета страницы, окно с двумя створками, кнопки пульта.
2. **Разметка** — заголовок, окно с холстом, подоконник, пустые ряды для кнопок пульта.
3. **Скрипт (`<script>`)** — всё, что рисует вид. В начале скрипта есть оглавление, разделы подписаны:

| Раздел | Что внутри |
|---|---|
| 1. Общее | размеры картинки, состояние `S` (что выбрано на пульте), помощники для цвета |
| 2. Свет и небо | цвета неба по часам (`KEY`), погода (`WX`), свет (`MOOD`), восход/закат и высота солнца, `env()` — расчёт освещения |
| 3. Примитивы | прямоугольники, многоугольники, окна домов |
| 4. Город | пятиэтажки, МГУ (`msu`), Сити (`moscowCity`), цирк (`circus`), кирпичный дом (`brick`), улица справа |
| 5. Деревья | клёны (`mkTree`), ближняя ветка, листья, ветер (`gust`, `sw`), `drawTrees()` |
| 6. Кадр | небо, звёзды, облака, провода, дым из труб, туман, дождь и снег — всё собирается в `frame()` |
| 7. Музыка | тишина или свой аудиофайл |
| 8. Управление | кнопки пульта, `refresh()`, прогноз погоды с open-meteo.com |

## Частые правки

- **Добавить погоду** — новая строка в `WX` (раздел 2). Поле `seasons` ограничивает времена года.
- **Цвет неба в какое-то время** — таблица `KEY` или особые случаи в `env()`.
- **Переставить дерево** — список `TREES` (раздел 5): x ствола, y верхушки, наклон.
- **Бегущие строки** — тексты `TM` (Меркурий) и `TK` (цирк) в разделе 6.
- **Место для прогноза** — `FC_URL` (широта и долгота в адресе).

## Обновление

Netlify подхватывает изменения из этого репозитория сам: достаточно заменить `index.html`.
Бот в Telegram открывает тот же сайт.
